La base al día

De dónde sale cada dato de la base de datos, quién lo publica, cada cuándo y cómo entra a la plataforma: lo que se actualiza solo cada semana, lo que un vigía detecta y se coteja, y lo que se integra a mano. Así sabes de qué fecha es cada cifra y cuándo esperar la siguiente.

En esta página: La base en números 🤖 Se actualiza sola 🔔 Avisa y se coteja ✋ Se integra a mano

La base en números

27fuentes de la base
6🤖 se actualizan solas cada semana
3🔔 avisan y se cotejan
18✋ se integran a mano

Las dependencias no publican cada día: cada fuente tiene su calendario. La base no se rehace a diario; se alimenta con cada novedad, y cada novedad pasa por el mismo camino: su huella, su cuadre y su chip. Lo que una dependencia no publica queda en el Registro de pendientes.

🤖 Se actualiza sola

El flujo «Base al día» la baja cada miércoles, rehace su cuadre y la publica si cambió. Si el archivo no cuadra o cambió de formato, se detiene y no publica nada.
